# Transformer Scratch Language Converter

Transformer-based language conversion (machine translation) implemented from scratch in PyTorch. The codebase focuses on building the core Transformer architecture, a bilingual dataset pipeline, and a training loop with validation and decoding.

## What This Project Does

- Trains an encoder-decoder Transformer for translation between two languages (default: English to Italian).
- Builds word-level tokenizers using Hugging Face `datasets` and `tokenizers`.
- Implements all Transformer blocks manually: embeddings, positional encoding, multi-head attention, encoder/decoder stacks, and projection.
- Provides a full training loop with logging, validation decoding, and checkpointing.

## Architecture Overview

The model is a standard Transformer (Vaswani et al., 2017) with a stack of encoder and decoder blocks:

1. **Input embeddings** scale token vectors by $\sqrt{d_{model}}$.
2. **Sinusoidal positional encoding** injects sequence order.
3. **Encoder stack** applies multi-head self-attention and feed-forward blocks with residual connections and layer norm.
4. **Decoder stack** applies masked self-attention, cross-attention over encoder outputs, and feed-forward blocks.
5. **Projection layer** maps decoder outputs to target vocabulary logits.

Implementation details live in [model.py](model.py).

### Core Components

- `InputEmbeddings`: token embedding lookup with scaling.
- `PositionalEncoding`: fixed sinusoidal encodings added to embeddings.
- `MultiAttentionBlock`: multi-head attention with masking support.
- `EncoderBlock` / `DecoderBlock`: residual + layer norm + attention + feed-forward.
- `Transformer`: wraps encode, decode, and project steps.

### Shapes (High Level)

- Encoder input: `(batch, seq_len)`
- Encoder mask: `(batch, 1, 1, seq_len)`
- Decoder input: `(batch, seq_len)`
- Decoder mask: `(batch, 1, seq_len, seq_len)`
- Encoder output: `(batch, seq_len, d_model)`
- Decoder output: `(batch, seq_len, d_model)`

## Data Pipeline

The data flow is implemented in [train.py](train.py) and [dataset.py](dataset.py).

1. **Dataset source**: `opus_books` from Hugging Face `datasets`.
2. **Tokenizer build**: a WordLevel tokenizer per language with `[UNK]`, `[PAD]`, `[SOS]`, `[EOS]`.
3. **Split**: 90% training / 10% validation.
4. **BilingualDataset**: builds encoder/decoder inputs, labels, and masks.

`BilingualDataset` returns:

- `encoder_input`: `[SOS] src_tokens [EOS] [PAD]*`
- `decoder_input`: `[SOS] tgt_tokens [PAD]*`
- `label`: `tgt_tokens [EOS] [PAD]*`
- `encoder_mask`: padding mask for source
- `decoder_mask`: padding mask AND causal mask

The causal mask is generated by `casual_mask` (causal, upper-triangular masking) in [dataset.py](dataset.py).

## Training Flow

Training is driven by [train.py](train.py):

- **Loss**: `CrossEntropyLoss` with label smoothing and `[PAD]` ignore index.
- **Optimizer**: Adam.
- **Validation**: greedy decoding + CER, WER, BLEU metrics.
- **Checkpoints**: saved every epoch to `opus_books_weights/`.

## Configuration

Default hyperparameters are defined in [config.py](config.py):

- `seq_len`: 350
- `d_model`: 512
- `batch_size`: 8
- `num_epochs`: 20
- `lang_src`: `en`
- `lang_tgt`: `it`

Adjust these values in [config.py](config.py) to change the model size, dataset languages, or training setup.

## How To Run

1. Install dependencies:

```bash
pip install torch datasets tokenizers torchmetrics tensorboard
```

2. Train the model:

```bash
python train.py
```

3. Check TensorBoard logs:

```bash
tensorboard --logdir runs
```
